## 3. 問題回答

### 問題一：測試一中，整理後的桌遊串列有 4 筆資料，為什麼桌遊費用應以 3 人計算？直接把字串拆成 `list`，和再轉成 `set`，各自保留了什麼、失去了什麼？
* **為什麼以 3 人計算**：因為規則規定「同一個人在同一場活動中重複出現，只算一位參加者，也只收一次該場費用」。測試一中 `amy` 重複報名了兩次，實際不重複的參加者只有 `amy`、`ben`、`cora` 共 3 位，因此應收費用為 $3 \times 120 = 360$ 元。
* **`list` 與 `set` 的差異**：
  * **直接拆成 `list`**：**保留了**所有原始報名紀錄的**順序**以及**重複出現的項目**（可看出 `amy` 報了兩次）；但**失去了**快速去除重複與直接進行數學集合運算（交集、聯集、差集）的便利性。
  * **再轉成 `set`**：**保留了**不重複的**唯一參加者名單**（自動合併重複的 `amy`）並支援集合比較運算；但**失去了**原本的**排列順序**（集合是無序的）以及**重複報名的次數資訊**。

### 問題二：測試三中，兩場活動只有 3 位不同的人，為什麼是 6 人次、總應收仍是 600 元？請用集合關係與算式說明。
* **集合關係說明**：在測試三中，桌遊集合 $A = \{\text{'amy'}, \text{'ben'}, \text{'cora'}\}$，電影集合 $B = \{\text{'amy'}, \text{'ben'}, \text{'cora'}\}$，兩者完全相等（$A = B$）。因此兩者的**聯集** $A \cup B = \{\text{'amy'}, \text{'ben'}, \text{'cora'}\}$，代表「總不重複人數」為 $|A \cup B| = 3$ 人。但兩場活動是分開計費的，**報名人次**是兩場各自去重人數的總和，即 $|A| + |B| = 3 + 3 = 6$ 人次。
* **算式說明**：這 3 位參加者同時報名並參加了兩場活動，依規則兩場費用分別計算：
  * 桌遊應收：$3 \text{ 人} \times 120 \text{ 元} = 360 \text{ 元}$
  * 電影應收：$3 \text{ 人} \times 80 \text{ 元} = 240 \text{ 元}$
  * 總應收：$360 + 240 = 600 \text{ 元}$。
